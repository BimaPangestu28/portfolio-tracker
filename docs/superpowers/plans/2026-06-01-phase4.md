# Investment Tracker — Phase 4 (Chatbot, 2 channels) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`). Backend tasks 1–5, frontend 6–8.

**Goal:** A read-only portfolio Q&A chatbot powered by Claude, reachable via an in-app chat panel and a WhatsApp webhook. The bot answers using an injected snapshot of the portfolio (net worth, holdings, allocation, recent transactions) — one Claude call per question, no tool-use loop, nothing auto-committed.

**Architecture:** A `chat_message` table + repo; a pure `build_context` that renders a portfolio snapshot to text; an `answer` service that stores the user message, fetches the snapshot via Phase 1 `build_summary` + repos, calls the Phase 3A Claude client, stores and returns the reply; in-app `/chat` + `/chat/history` endpoints; a WhatsApp webhook (GET verify + POST inbound parse → shared core, outbound send stubbed pending credentials). A React Chat page. No `unwrap`/`panic` in production; secrets not logged.

**Tech Stack:** Rust/axum/sqlx + the existing `llm::claude` client (Phase 3A); React/TS/zod/TanStack Query/Tailwind + Vitest/MSW. Follow existing conventions.

**Builds on:** Phase 1 `service::portfolio::build_summary`, repos (`instruments`, `transactions`); Phase 3A `llm::claude::{ClaudeClient, Part}`. READ those for signatures. WORK IN THE CURRENT WORKTREE on branch `phase4`.

```rust
/// Render a compact text snapshot of the portfolio for the LLM context.
pub fn build_context(s: &PortfolioSummary) -> String {
    let mut out = String::new();
    out.push_str(&format!("Net worth: Rp {} (USD {}).\n", s.net_worth_idr, s.net_worth_usd));
    out.push_str(&format!("Unrealized P&L (IDR): {}. Realized P&L (IDR): {}.\n", s.total_unrealized_pnl_idr, s.total_realized_pnl_idr));
    match s.xirr { Some(x) => out.push_str(&format!("XIRR: {:.1}%\n", x * 100.0)), None => out.push_str("XIRR: n/a\n") }
    out.push_str("Allocation (actual% / target%):\n");
    for c in &s.allocation {
        out.push_str(&format!("- {}: {}% / {}%{}\n", c.name, c.actual_pct, c.target_pct, if c.out_of_band { " (OUT OF BAND)" } else { "" }));
    }
    out.push_str("Holdings:\n");
    for p in &s.positions {
        out.push_str(&format!("- instrument#{}: qty {} value Rp {}\n", p.instrument_id, p.quantity, p.market_value_idr));
    }
    out
}
```

```rust
use crate::db::Db;
use crate::llm::claude::{ClaudeClient, Part};
use crate::repo::chat;

const SYSTEM: &str = "You are a concise personal investment assistant. Answer the user's question using ONLY the portfolio snapshot provided. Amounts are in IDR unless noted. If the snapshot lacks the info, say so briefly. Keep answers short.";

/// Store the user message, build context from the current portfolio, ask Claude, store + return the reply.
pub async fn answer(db: &Db, client: &ClaudeClient, channel: &str, user_msg: &str) -> anyhow::Result<String> {
    chat::add(db, "user", user_msg, channel).await?;
    let summary = crate::service::portfolio::build_summary(db).await?;
    let context = build_context(&summary);
    let prompt = format!("Portfolio snapshot:\n{context}\n\nUser question: {user_msg}");
    let reply = client.complete(SYSTEM, &[Part::Text(prompt)]).await
        .map_err(|e| anyhow::anyhow!("llm error: {e}"))?;
    chat::add(db, "assistant", &reply, channel).await?;
    Ok(reply)
}
```

```rust
use crate::error::AppError;
use crate::llm::claude::ClaudeClient;
use crate::repo::chat;
use crate::AppState;
use axum::{extract::State, Json};
use serde::{Deserialize, Serialize};

#[derive(Deserialize)]
pub struct ChatIn { pub message: String }
#[derive(Serialize)]
pub struct ChatOut { pub reply: String }

pub async fn post_chat(State(s): State<AppState>, Json(b): Json<ChatIn>) -> Result<Json<ChatOut>, AppError> {
    if b.message.trim().is_empty() { return Err(AppError::BadRequest("empty message".into())); }
    let client = ClaudeClient::from_env().map_err(|e| AppError::Other(anyhow::anyhow!("chat unavailable: {e}")))?;
    let reply = crate::service::chat::answer(&s.db, &client, "inapp", &b.message).await.map_err(AppError::Other)?;
    Ok(Json(ChatOut { reply }))
}

pub async fn history(State(s): State<AppState>) -> Result<Json<Vec<chat::ChatMessageRow>>, AppError> {
    Ok(Json(chat::history(&s.db, 100).await.map_err(AppError::Other)?))
}
```

```rust
/// Extract (from, text) from a Meta WhatsApp Cloud API webhook payload. None if not a text message.
pub fn parse_inbound(payload: &serde_json::Value) -> Option<(String, String)> {
    let msg = payload.pointer("/entry/0/changes/0/value/messages/0")?;
    let from = msg.get("from")?.as_str()?.to_string();
    let text = msg.pointer("/text/body")?.as_str()?.to_string();

}
```

```rust
use crate::error::AppError;
use crate::llm::claude::ClaudeClient;
use crate::AppState;
use axum::{extract::{Query, State}, http::StatusCode, response::IntoResponse, Json};
use std::collections::HashMap;

/// GET verify: echo hub.challenge when hub.verify_token matches env WHATSAPP_VERIFY_TOKEN.
pub async fn verify(Query(q): Query<HashMap<String, String>>) -> impl IntoResponse {
    let expected = std::env::var("WHATSAPP_VERIFY_TOKEN").unwrap_or_default();
    if q.get("hub.mode").map(|m| m == "subscribe").unwrap_or(false)
        && !expected.is_empty()
        && q.get("hub.verify_token") == Some(&expected) {
        if let Some(ch) = q.get("hub.challenge") { return (StatusCode::OK, ch.clone()); }
    }
    (StatusCode::FORBIDDEN, "forbidden".to_string())
}

/// Best-effort outbound send. Live Graph API send is deferred (needs WHATSAPP_TOKEN + phone id);
/// when unconfigured it logs and returns Ok so inbound handling still succeeds.
async fn send_whatsapp(to: &str, body: &str) {
    if std::env::var("WHATSAPP_TOKEN").is_err() {
        tracing::info!("[whatsapp stub] would send to {to}: {body}");
        return;
    }
    // Live send intentionally deferred in Phase 4 MVP.
    tracing::info!("[whatsapp] send to {to} ({} chars)", body.len());
}

pub async fn inbound(State(s): State<AppState>, Json(payload): Json<serde_json::Value>) -> impl IntoResponse {
    if let Some((from, text)) = parse_inbound(&payload) {
        match ClaudeClient::from_env() {
            Ok(client) => match crate::service::chat::answer(&s.db, &client, "whatsapp", &text).await {
                Ok(reply) => send_whatsapp(&from, &reply).await,
                Err(e) => tracing::warn!("whatsapp chat error: {e}"),
            },
            Err(e) => tracing::warn!("whatsapp chat unavailable: {e}"),
        }
    }
    // Always 200 to Meta so it doesn't retry.
    StatusCode::OK
}
```
