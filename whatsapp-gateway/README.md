# WhatsApp Gateway (Baileys)

Bridges WhatsApp ↔ the portfolio chatbot using Baileys (WhatsApp Web, QR pairing — no Meta account).

## Run
1. Start the backend (`cd ../backend && cargo run`, needs `ANTHROPIC_API_KEY`).
2. `cd whatsapp-gateway && npm install && BACKEND_URL=http://localhost:8080 GATEWAY_TOKEN=<shared-secret> npm start`
3. Open the web app, go to the **WhatsApp** page, click **Connect**, and scan the QR shown there with WhatsApp (Linked Devices). Creds persist in `auth_state/`. (The QR is also reported to the backend; nothing prints in the terminal anymore.)
4. Message the linked number; replies are generated by the chatbot.

Set the same `GATEWAY_TOKEN` env on the backend so it authenticates gateway calls.
